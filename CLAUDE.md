# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Active Plugins

The following Claude Code plugins are enabled via `.claude/settings.json`:

- **superpowers** — extended skill-based workflows
- **context7** — library documentation lookup via `use context7`
- **playwright** — browser automation and testing

## Documented Solutions

`docs/solutions/` — documented solutions to past problems (runtime errors, deployment issues, best practices), organized by category with YAML frontmatter (`module`, `tags`, `problem_type`). Relevant when debugging or implementing in documented areas.
